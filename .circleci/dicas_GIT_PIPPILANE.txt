CircleCI detecta o push → Baixa o código do GitHub → Roda os testes

4️⃣ Sem o push, o CircleCI não vê o arquivo novo
O CircleCI só enxerga o que está no GitHub, não o que está no seu computador.

✅ Com commit + push: CircleCI vê e executa o teste
❌ Sem commit + push: CircleCI continua executando a versão antiga (só o teste básico)
